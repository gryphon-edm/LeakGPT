# ✦ What is LeakGPT?

**LeakGPT** is an experimental **AI-powered anti-corruption and whistleblowing intelligence platform**.

The goal is simple:

**Give people better tools for understanding evidence of corruption, fraud, conflicts of interest, financial misconduct, and institutional abuse.**

Instead of forcing investigators to manually process enormous amounts of information, LeakGPT provides an AI-assisted layer capable of helping analyze and structure information.

Potential inputs can include:

- Whistleblower reports
- Financial records
- Corporate documents
- Contracts
- Public disclosures
- Emails and communications
- Transaction histories
- Government records
- Investigative datasets

The system is designed to help turn disconnected information into **structured investigative leads**.

# ✦ Anonymous Whistleblowing ✦

LeakGPT is designed around the principle that **people who expose wrongdoing should have tools that prioritize their safety and control over their information.**

A whistleblower may possess information that is:

- financially significant
- politically sensitive
- legally important
- difficult to interpret
- distributed across thousands of documents

The objective is to provide an intelligence layer that can help transform raw disclosures into structured information.

### **From leak → evidence → pattern → lead**

# ⚠️ Fraud Detection

Fraud often becomes visible through relationships rather than individual events.

LeakGPT can be used as an analytical framework for identifying potential signals such as:

- anomalous transactions
- repeated counterparties
- unusual payment patterns
- inconsistent financial information
- suspicious corporate relationships
- procurement anomalies
- unexplained transfers
- unusual timing
- repeated behavioral patterns

The AI does **not** replace an investigator.

It helps investigators determine **where to look next**.

# ⚡ Quick Start

Clone the repository:

```bash
git clone https://github.com/gryphon-edm/LeakGPT.git

cd LeakGPT
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it.

### macOS / Linux

```bash
source .venv/bin/activate
```

### Windows

```powershell
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

Open:

```text
http://localhost:8000
```

The repository currently documents Python 3.8+ as the baseline requirement. :contentReference[oaicite:3]{index=3}

# ✦ Responsible Intelligence ✦

LeakGPT is designed for **lawful, ethical, and defensive investigation**.

AI-generated findings are **not proof of wrongdoing**.

A flagged transaction, person, organization, or relationship should be treated as an investigative lead requiring independent verification.

### Never use LeakGPT to:

- fabricate accusations
- harass individuals
- publish unverified allegations
- expose private information unnecessarily
- impersonate whistleblowers
- compromise systems without authorization
- process sensitive data without appropriate safeguards

The purpose is to **increase investigative capability, not replace investigative judgment.**

---

# 🔐 Privacy & Security

If deployed for real whistleblowing workflows, operators should implement appropriate security controls before accepting sensitive information.

Recommended considerations include:

- Encryption in transit
- Encryption at rest
- Access control
- Secure secrets management
- Minimal data retention
- Audit logging
- Secure infrastructure
- Threat modeling
- Metadata minimization
- Secure deletion procedures

**Do not assume that a self-hosted deployment is automatically anonymous or secure.**

Operational security depends on the entire deployment environment.
